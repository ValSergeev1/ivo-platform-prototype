# IVO Platform prototype · V01 (sample data)

Step 2 of the IVO work order: a clickable front-end prototype of the new IVO system, reviewed by link before anything is built.
Static HTML/CSS/JS, no backend, no build step for the browser. **Everything is fictional sample data.** Nothing is sent, saved or connected to ivoservgroup.com or the live console.

Start at `index.html` (V01). A V01 / V02 switch on the home page opens the V02 design at `v2/`, which keeps the same sample flows in a new layout. V01 URLs are unchanged.

| Part | Path | Screens |
|---|---|---|
| Staff console (desktop) | `console/` | overview, approval inbox, inquiry triage, requests, job timeline, outbound bid packets, bidding on outside contracts (pipeline, package extraction, sub confirmations, leveling, bid form, won/lost), integrations, contractor directory, applications, team and roles |
| Customer app (phone, installable) | `customer/` | invite, email-code sign-in, home, 8-step request wizard, emergency button, job tracker, change order vs NTE, closeout sign-off, documents, company users, account |
| Customer portal (desktop) | `customer-portal/` | dashboard, requests, job, new request, approvals, documents, properties, users |
| Contractor app (phone, installable) | `contractor/` | sign-in, opportunities, packet, bid wizard, bid confirmation request, jobs and schedule, check-in, punch list, change-order request, closeout, compliance, company and crew |
| Vendor portal (desktop) | `vendor-portal/` | overview and scorecard, opportunities, bid confirmation, packet and bid, bids, jobs and crew schedule, compliance, company and crew |
| Decision: contractor application | `apply/` | options A / B / C side by side, each clickable step by step, with a recommendation |
| Decision: customer onboarding | `onboarding/` | options 1 / 2 / 3 side by side, clickable, with a recommendation |

Launch scope (locked by the owner, then extended Nov 13, 2026): the AI bidding module and subcontractor outreach (always with admin approval) and platform integrations are in scope. Payments, SMS, store apps and public self-serve still appear only as greyed **Later** placeholders. Routing suggestions are rule-based.

Source: `src/*.html` fragments are wrapped by `python3 build.py` (shared head, noindex, "Prototype – sample data" banner). `python3 gen_decisions.py` regenerates `src/apply.html` and `src/onboarding.html`. Shared UI: `assets/css/app.css`, `assets/js/app.js`. Screenshots: `screens/` (V01) and `screens/v2/` (V02). V02 source is generated by `python3 gen_v2.py` into `v2/`. **V03** (complete redesign, `v3/`) is generated by `python3 gen_v3.py` (modules in `gen3/`, CSS `v3/assets/css/ivo-os.css`, JS `v3/assets/js/ivo-os.js`), screenshots in `screens/v3/`.

noindex is set on every page and `robots.txt` disallows all crawling.
